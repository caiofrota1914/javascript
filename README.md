# 📘 Estudos de JavaScript

Repositório de estudos criado para registrar exercícios e fundamentos de **JavaScript** durante minha evolução em desenvolvimento Web.

## 📚 Conteúdos praticados

- Tipos primitivos
- Variáveis
- Template strings
- Funções
- Operadores aritméticos
- Operadores relacionais
- Comparações com `==` e `===`
- Operadores lógicos

## 🎯 Objetivo

Manter um histórico dos conceitos estudados e evoluir este repositório conforme novos conteúdos de JavaScript forem aprendidos.

> Este é um repositório de estudos e experimentação, não um projeto final de portfólio.
